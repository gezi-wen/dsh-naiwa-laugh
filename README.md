## 它怎么来的（都市传说版）

据说是有人想用 AI 生成某个黄色 IP，结果模型跑偏了，长出了一只蛤。

创作者发现之后连夜跑路，不敢认自己的娃 —— **蛙母也害怕天道惩罚啊**。

于是它就这么无主地漂在互联网上，被网友养成了「黄色三幻神」之一，和牛来、美团袋鼠并列。
网友对它的评价是：**什么都没做，但看起来已经看透了一切。**

现在它住进你每天写代码的软件里。

## 它到底干什么

- **什么时候响** —— 一轮 agent 回合走完（`turn/end`）。就算跑崩了、被你打断了，也算一轮走完，照样笑。
- **响什么** —— `assets/` 里随机抽一个。其中有一个是祖传正版，抽中概率是别人的两倍。
- **多久响一次** —— 一轮一次。你聊十句，它笑十次。
- **响多久** —— 最长 7.4 秒。嫌长你可以自己剪。
- **刷新页面会不会突然响** —— 不会。它对过一次数才敢开口。

## 怎么让它临时闭嘴

浏览器控制台：

```js
__dshNaiwa.setEnabled(false)         // 闭嘴
__dshNaiwa.setEnabled(true)          // 回来
__dshNaiwa.test()                    // 手动来一声
__dshNaiwa.list()                    // 看看它兜里都有什么
__dshNaiwa.play('naiwa-main.mp3')    // 点名要那一个
```

刷新页面会把开关重置回「开」。这是特性，不是 bug —— 你总会重新打开它的。

## 两个不显然的地方

**一、第一次响之前，你可能得先点一下页面。**

浏览器规定：没有真实用户手势，音频一律不许出声。所以它会趁你第一次点击或按键时悄悄解锁，之后才敢响。
不是你设置错了，它也没坏，是它没办法。

**二、它在你打字的时候装死。**

用中文输入法组字期间，它不解锁、不预热、不碰 DOM。
因为一旦在那时候初始化音频上下文，微软拼音就会把候选词直接上屏、光标跳到最前面。谁碰谁死。

## 已知边界

- 只在 Web UI 里响（桌面版和网页版是同一个页面）。不弹系统通知。
- 不联网、不写注册表、不收集任何东西。它唯一会做的事是笑。
- 音效事先解码进内存，响的时候没有加载延迟；代价是常驻几 MB。
- 切到别的标签页或最小化窗口时，音频上下文会主动挂起 —— 免得地球 Online 服务器因为你开着这个插件就不肯睡。
